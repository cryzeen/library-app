# Веб-сайт бази даних бібліотеки (Тема №22)

Каталог книжкового фонду та система формування читацьких заявок.
Поточний етап (Лабораторна робота 3.2): асинхронний сервісний шар доступу до даних, автономне збереження заявок через `mockRequestService` (`localStorage`), підготовлений REST-адаптер на `fetch`, керування станами завантаження/помилок і захист від застарілих відповідей.

## Середовище розробки
- **ОС:** Windows 11 (Варіант А: нативна розробка + Docker Desktop)
- **Node.js:** v24.21.0
- **npm:** 11.19.0
- **Git:** 2.55.0.windows.5
- **Docker:** 29.8.0 (build 88096ef)
