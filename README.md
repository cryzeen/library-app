# Веб-сайт бази даних бібліотеки

Навчальний курсовий проєкт з дисципліни **«Технологія компонентного програмування для веб»** (Варіант № 22).

Застосунок призначений для автоматизації процесів перегляду книжкового фонду бібліотеки та формування читацьких заявок на видачу літератури. Реалізований як односторінковий вебзастосунок (Single Page Application, SPA) на базі бібліотеки ReactJS.

---

## Функціональні можливості

1. **Модуль каталогу видань (`/books`)**:
   * Перегляд переліку книг із можливістю пошуку за назвою та автором.
   * Фільтрація за наявністю примірників із синхронізацією стану в параметрах URL (`?q=...&available=1`).
   * Перегляд детальної картки видання (`/books/:bookId`).

2. **Модуль обслуговування читацьких заявок (`/loans`)**:
   * Оформлення нової заявки на видачу обраної книги (`/loans/new?bookId=...`).
   * Перевірка вхідних даних за допомогою чистої функції валідації (`ticketNumber`, `durationDays`, `readingRoomOnly`).
   * Захист чернетки користувача та збереження даних при збоях мережевої взаємодії.
   * Управління списком заявок (перегляд, редагування, видалення з підтвердженням).

3. **Асинхронний сервісний шар**:
   * Реалізація автономного адаптера `mockRequestService` із синхронізацією в `localStorage` (`library.requests.v1`).
   * Архітектурна готовність до роботи з зовнішнім REST API (`apiRequestService`).

4. **Автоматизоване тестування**:
   * Перевірка бізнес-правил валідації в доменному шарі.
   * Тестування компонентів форм, стану блокування кнопок під час запитів та обробки помилок.
   * Інтеграційні тести маршрутизації та обробників подій.
   * Тестування мережевого адаптера HTTP-відповідей.

## Технологічний стек

* **Основна бібліотека**: React 18, JavaScript (ES6+)
* **Інструмент збірки**: Vite
* **Маршрутизація**: React Router 6
* **Керування станом**: React Context API (`RequestsProvider`, `BookSelectionProvider`)
* **Тестове середовище**: Vitest, React Testing Library, `@testing-library/user-event`, `jsdom`
* **Стилізація**: CSS (Flexbox / Grid)

## Інструкція з розгортання та запуску

### 1. Встановлення залежностей
Перед початком роботи переконайтеся, що в системі встановлено Node.js (версії 18+) та npm. У кореневій директорії проєкту виконайте:

```bash
npm install
```

### 2. Запуск у режимі розробки
Для запуску локального сервера розробки виконайте:

```bash
npm run dev
```
Після запуску застосунок буде доступний за адресою: `http://localhost:5173`

### 3. Запуск автоматизованих тестів
Для виконання набору модульних та інтеграційних тестів:

```bash
# Одноразовий запуск усіх тестів
npm run test:run

# Запуск тестів у режимі відстеження змін
npm run test
```

### 4. Збірка та перевірка виробничої версії
Для компіляції оптимізованого виробничого бандла:

```bash
npm run build
```

Для локального перегляду згенерованої збірки з каталогу `dist/`:

```bash
npm run preview
```
Сервер попереднього перегляду буде доступний за адресою: `http://localhost:4173`
